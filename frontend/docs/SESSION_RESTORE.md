# 새로고침 시 세션 복원 (HODL-125)

헤더와 보호 화면은 `GET /api/v1/me`가 완료될 때까지 로그인 상태 판단을 보류한다.
access 쿠키로 회원 정보를 받으면 갱신 없이 복원한다. 401이면 공유 갱신을 시도하고
성공 후 회원 정보를 다시 조회한다. 갱신도 401이면 글쓰기 같은 보호 화면은 로그인
페이지로 이동한다. 일시적인 조회·갱신 오류가 발생하면 현재 주소를 유지하고 재시도
버튼을 표시한다.

인증 쿠키와 갱신 동작은 HODL-129의 동일 출처 프록시 및 Rust 계약을 따른다.
자세한 설정은 [쿠키 인증 문서](../AUTH_COOKIES.md)를 참고한다.

## 회귀 테스트

`frontend/`에서 `pnpm run test:e2e`로 실행한다. 유효한 access 쿠키만 있는
상태에서 홈과 글쓰기를 새로고침하고, 느린 복원 동안 로그인 링크와 리다이렉트가
보류되는지 확인한다. 공유 인증 테스트는 세션 만료 시 로그인 이동, 일시적인 오류
후 재시도, 새 탭 복원, 쿠키 갱신과 로그아웃도 확인한다.
