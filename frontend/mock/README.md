# 가짜 API 서버 (로컬 화면 확인용)

실제 백엔드 없이 화면을 눌러 볼 때 쓴다. 의존성 없이 Node 만으로 돈다.

```
pnpm dev:mock
```

가짜 서버(`http://localhost:8787`)와 `next dev`(`http://localhost:3000`)가 같이 뜬다.
`.env.local` 은 건드리지 않는다 — 실제 API 로 돌아가려면 그냥 `pnpm dev` 를 쓰면 된다.

## 로그인

처음에는 **관리자로 로그인된 상태**다.

| 하고 싶은 것                   | 방법                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 일반 회원으로 보기             | 로그아웃 → 아무 아이디(예: `user`)로 로그인. 비밀번호는 보지 않는다                                                   |
| 관리자로 보기                  | 아이디에 `admin` 이 들어가게 로그인                                                                                   |
| 처음부터 일반 회원 · 로그인 전 | `MOCK_ROLE=USER pnpm dev:mock` · `MOCK_ROLE=GUEST pnpm dev:mock` (PowerShell: `$env:MOCK_ROLE="USER"; pnpm dev:mock`) |

## 볼 수 있는 것

| 화면        | 주소                                               | 들어 있는 데이터                                                                                     |
| ----------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 홈 · ETH 방 | `/` · `/subhodl/ETH`                               | 배지 상태마다 글 한 건: 고래 · 상어 · 돌고래(거래소, 일부 조회) · 새우 · 미보유 · 미인증 · 조회 실패 |
| 글 상세     | `/subhodl/ETH/1`                                   | 댓글 5개(동물 배지 · 답글 · 미보유 · 미인증 · 조회 실패)                                             |
| 옛 배지     | `/subhodl/BTC`                                     | 등급 설정 전의 글 → 예전 `지갑연결` 배지                                                             |
| 관리자      | `/admin`                                           | 방 관리 · 등급 설정(ETH) · 뉴스 · 투표 · 배너                                                        |
| 닫힌 방     | `/subhodl/DOGE`                                    | 닫힌 방 안내                                                                                         |
| 홈 배너     | `/`                                                | 노출 배너 2장(뽑기로 가는 링크 · 링크 없음). 숨긴 배너 1장은 관리 화면에서만                         |
| 뽑기        | `/draw/1` · `/draw/2` · `/draw/3` · `/draw/4`      | 진행 중 · 시작 전 · 종료 · 중지. 1번은 뽑으면 결과가 남고 다시 눌러도 같다                           |
| 지난 투표   | `/subhodl/ETH/polls`                               | 사흘치 결과. 어제는 전체와 보유자가 반대로 갈림, 그제는 반반, 사흘 전은 보유자 집계 없음             |
| 내 투표     | `/mypage/votes`                                    | 두 건                                                                                                |
| 검색        | `/search?q=배지` · `/search?q=배지&room=ETH`       | 분류별 미리보기. 글이 5건을 넘어 "모두 보기" 로 분류 화면에 간다. `/search?q=zzz` 는 결과 없음       |
| 방 통계     | `/subhodl/ETH` · `/subhodl/SOL` · `/subhodl/OTHER` | 참여자 · 보유 인증률(24시간 · 누적) · 참여자 없음 · 인증률 숨김                                      |

## 알아둘 것

- 가짜 서버의 이미지는 전부 1×1 점 하나를 늘린 것이다. 배너 · 상품 그림은 단색 칸으로 보인다(자리와 비율만 확인).
- 값은 메모리에만 있다. 서버를 다시 켜면 처음 상태로 돌아간다.
- **여기서 된다고 실제 API 에서 되는 것은 아니다.** 길이 · 권한 · 동시성 같은 서버 쪽 검사는 대부분 없다.
  실제 확인은 `pnpm dev` 로 운영 API 에 붙여서 한다.
- 시세 · 차트는 가짜 서버를 거치지 않는다(브라우저가 업비트 · TradingView 를 직접 부른다).
- 지갑 · 거래소 · 임시저장 · 글쓰기 발행은 비어 있거나 없다. 없는 주소를 부르면 404 와 함께
  터미널에 그 주소가 찍힌다 — 필요하면 `mock/server.mjs` 에 한 줄 더한다.
- 처음 데이터는 `mock/seed.mjs` 에 있다. 전부 지어낸 값이다.
