인증 세션

토큰은 이 탭의 메모리에만 저장됩니다.

먼저 회원가입하거나 로그인하세요.

EVM 지갑

브라우저 확장이나 WalletConnect 호환 모바일 앱에서 personal_sign으로 소유권을 증명합니다.

모바일에서는 지갑 선택 후 설치된 앱으로 이동합니다. 개인키·시드 문구를 입력하지 마세요. 자산 조회에는 ETHEREUM_RPC_URL이 필요합니다.

연결된 지갑을 조회할 수 있습니다.

게시글

작성하면 게시글 ID가 아래 기능에 자동으로 적용됩니다.

작성·수정·삭제는 인증 화면에서 로그인 후 사용할 수 있습니다. 수정 시 첨부 미디어는 입력한 URL 목록으로 대체됩니다.

응답이 여기에 표시됩니다.

피드

처음부터 조회한 뒤 다음 페이지 버튼으로 커서를 이어갑니다.

아직 피드를 조회하지 않았습니다.
응답이 여기에 표시됩니다.

댓글

위 게시글 ID를 사용하며, 작성한 댓글 ID는 자동 입력됩니다.

응답이 여기에 표시됩니다.

게시글 반응

위 게시글 ID에 좋아요·북마크·재게시를 적용합니다.

응답이 여기에 표시됩니다.

팔로우

다른 회원 ID를 입력해 팔로우 관계를 테스트합니다.

응답이 여기에 표시됩니다.

미디어

업로드한 URL과 유형은 게시글 작성 칸에 자동 입력됩니다.

게시글에 연결한 파일은 이 버튼으로 삭제할 수 없습니다.

응답이 여기에 표시됩니다.

거래소 자산

업비트·빗썸·코인원 API 키를 연결하고 현재 잔고를 조회합니다.

반드시 자산조회/잔고조회 전용 키를 발급하고 서버의 공개 IP를 허용하세요. 이 화면은 추가 주문·출금 권한 유무를 검증하지 못합니다. 키는 성공적으로 잔고를 조회한 후 암호화 저장되며 응답에는 표시되지 않습니다.

응답이 여기에 표시됩니다.
